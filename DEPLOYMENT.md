# Render Deployment Guide

This project includes automated configuration (`render.yaml`) and dynamic URL resolution for low-config deployment on Render.

The app has three pieces:

- `backend`: Express API — a Render **Web Service**
- Render **Postgres** database (attached to the backend)
- `frontend`: Vite React static app — a Render **Static Site**

---

## Database

Create a Render Postgres instance first (Dashboard → **New +** → **PostgreSQL**). Copy its **Internal Database URL** if the backend service is in the same region (faster, free), or the **External Database URL** if connecting from outside Render (e.g. running migrations from your machine).

Apply the schema to it once, from `backend/`, with `DATABASE_URL` set in your environment:

```bash
npx prisma migrate deploy
```

---

## ⚡ Option 1: 1-Click Render Blueprint (Recommended)

1. Go to [Render Dashboard](https://dashboard.render.com/) and click **New +** → **Blueprint**.
2. Connect your GitHub repository.
3. Render reads `render.yaml` and creates both:
   - **`skillforce-backend`** (Node.js Web Service)
   - **`skillforce-frontend`** (Static Site with SPA rewrite rules & automatic API URL injection)
4. When prompted for the `skillforce-backend` env vars, fill in:
   - `DATABASE_URL` — your Postgres connection string from above
   - `GEMINI_API_KEY` and/or `OPENAI_API_KEY` (optional, for AI features)
5. Click **Apply**.

`JWT_SECRET` is auto-generated by the blueprint; `VITE_API_URL` on the frontend is wired automatically to the backend's host.

## 🛠️ Option 2: Manual Render Setup

### 1. Deploy Backend (Web Service)
- **Root Directory**: `backend`
- **Runtime**: `Node`
- **Build Command**: `npm install && npm run build && npm run prisma:deploy`
- **Start Command**: `npm start`
- **Environment Variables**:
  - `DATABASE_URL`: your Render Postgres connection string
  - `JWT_SECRET`: a long random string
  - `GEMINI_API_KEY`: optional
  - `OPENAI_API_KEY`: optional

Render sets `PORT` automatically — the server already reads it via `process.env.PORT`.

### 2. Deploy Frontend (Static Site)
- **Root Directory**: `frontend`
- **Build Command**: `npm install && npm run build`
- **Publish Directory**: `dist`
- **Redirects / Rewrites** (only needed if not using the Blueprint, which sets this already):
  - **Type**: `Rewrite`
  - **Source**: `/*`
  - **Destination**: `/index.html`

  A `public/_redirects` file (`/*  /index.html  200`) is also included in the repo and gets copied into `dist/` on build, so most Render static-site setups pick the rewrite up automatically without dashboard config.
- **Environment Variables**:
  - `VITE_API_URL`: `https://your-backend-service.onrender.com` (optional — see below)

---

## 🔄 Automatic URL Pairing

The frontend can resolve the backend URL without `VITE_API_URL` being set:
- If frontend is `https://skillforge-frontend.onrender.com`, it automatically targets `https://skillforge-backend.onrender.com`.
- Local development targets `http://localhost:5000` or the local network IP automatically.

`VITE_API_URL` is baked in at build time — after changing it, rebuild and redeploy the frontend.
